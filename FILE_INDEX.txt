WHAT EACH FILE DOES
═══════════════════

AGENT.JSX
└─ User interface for:
   ├─ Searching companies
   ├─ Displaying research
   ├─ Finding emails
   └─ Generating personalized emails

AGENT.CSS
└─ All styling for Agent interface
└─ Dark theme, responsive, animations

SETTINGS.JSX
└─ User profile form
└─ Stores: Name, role, location, LinkedIn, services, target market
└─ Drives everything else!

SETTINGS.CSS
└─ Styling for Settings form
└─ Validation feedback, save confirmation

APP.JSX
└─ Root component
└─ Wraps everything with ProfileProvider
└─ Tab navigation

PROFILECONTEXT.JS
└─ React context managing profile state
└─ localStorage persistence
└─ useProfile() hook for components to access profile

APICLIENT.JS
└─ Frontend API client
└─ Methods to call backend functions
└─ researchCompany()
└─ findDecisionMakerEmails()
└─ generateDecisionMakerEmail()

RESEARCH-ENHANCED.JS
└─ Backend function
└─ Takes: companyName + userProfile
└─ Returns: research with fit score, pain points, executives
└─ Uses: Claude API

FIND-DECISION-MAKER-EMAILS.JS
└─ Backend function
└─ Takes: companyName + role + userProfile
└─ Returns: List of people with verified emails
└─ Uses: Claude API + QuickEmailVerification API

BUSINESS-DEVELOPER-AGENT.JS
└─ Backend function
└─ Takes: Company + person + research + profile
└─ Returns: 3 personalized email variants
└─ Uses: Claude API (25-year BD expert persona)
