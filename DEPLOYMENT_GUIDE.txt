    1. Go to https://quickemailverification.com/register
    2. Sign up (no credit card needed)
    3. Copy API key from dashboard

TROUBLESHOOTING
━━━━━━━━━━━━━━

Issue: "Email verification API key not configured"
Fix: Check Netlify Environment variables
     Make sure QUICKEMAILVERIFICATION_API_KEY is there
     Redeploy after adding

Issue: "Failed to parse Claude response"
Fix: Check Claude's response format
    Likely issue: Claude returned markdown instead of JSON
    Add to function: text.replace(/```json|```/g, '')

Issue: "Email finding returns 0 results"
Fix: This is normal if Claude can't guess the domain
    Try company with more recognizable domain (paystack.com, etc)

Issue: Component shows "Complete Your Profile First"
Fix: Go to Settings tab and fill out all fields
     Save profile
     Return to Agent tab

Issue: "API call to /research-enhanced failed"
Fix: Check browser console for error
     Likely: ANTHROPIC_API_KEY not set in Netlify
     Add it to Environment variables and redeploy

WHAT HAPPENS ON DEPLOY
━━━━━━━━━━━━━━━━━━━━

When you push to GitHub, Netlify automatically:

1. Pulls latest code
2. Installs dependencies (npm install)
3. Builds frontend (npm run build)
4. Bundles Netlify Functions
5. Deploys everything

Build commands from netlify.toml:
□ Command: npm run build
□ Functions: netlify/functions
□ Publish: dist
